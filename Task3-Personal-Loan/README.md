# 💳 Personal Loan Acceptance Prediction (Task 5)

## 📌 Objective
The objective of this task is to predict whether a customer is likely to **accept a personal loan offer** based on demographic and financial features using **Logistic Regression**.

---

## 📂 Dataset
**Bank Marketing Dataset (UCI Machine Learning Repository)**

**Key features include:**
- Age
- Job
- Marital status
- Education
- Balance
- Housing loan
- Personal loan
- Target: Deposit (Yes/No)

---

## 🛠️ Tools & Technologies
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Jupyter Notebook

---

## 🔍 Approach
1. Explored dataset structure and features
2. Verified absence of missing values
3. Performed categorical encoding using One-Hot Encoding
4. Conducted Exploratory Data Analysis (EDA):
   - Loan acceptance distribution
   - Age vs Loan Acceptance
   - Balance vs Loan Acceptance
   - Job vs Loan Acceptance
5. Split data into training and testing sets
6. Applied feature scaling
7. Trained a **Logistic Regression** model
8. Evaluated model performance using:
   - Accuracy
   - Confusion Matrix

---

## 📊 Results
- Achieved strong classification accuracy
- Confusion matrix shows effective separation between customers likely and unlikely to accept loans

---

## 🧠 Key Insights
- Customers with higher balances are more likely to accept loans
- Certain job categories show higher acceptance rates
- Age plays a noticeable role in decision patterns

---

## ✅ Conclusion
This project demonstrates how classification models can support **business decision-making** by identifying customer segments with higher probability of loan acceptance.
